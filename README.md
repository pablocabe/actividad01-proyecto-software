# Actividad 01

- Versión 1: Claude Opus 5.0
- Versión 2: Cursor Grok 4.6

**Pasos para ejecutar el proyecto localmente**

1. **Clonar el repositorio**
   Ejecutá:

   `git clone [URL_DEL_REPOSITORIO]`

2. **Levantar el servidor local**

   Dentro de alguna de las dos versiones del proyecto, ejecuta el siguiente comando en la terminal:
   `python3 -m http.server`

3. **Ver el sitio en el navegador**

   Abrí tu navegador web e ingresá a la siguiente dirección:
   `http://localhost:8000`
